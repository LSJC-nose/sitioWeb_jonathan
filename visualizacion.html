Visualización de Resultados Gráficos

Presentación interactiva de resultados analíticos

Esta sección presenta gráficos generados a partir de los ejercicios realizados con Pentaho. Los gráficos se han implementado utilizando HTML, CSS y JavaScript para demostrar la capacidad de presentar resultados analíticos de manera visual e interactiva.

Ventas por Producto

Este gráfico muestra las ventas totales por producto, generado a partir del análisis del cubo OLAP.

Explicación Técnica

Este gráfico de barras utiliza Chart.js para visualizar los datos. Los datos se obtienen de consultas MDX ejecutadas sobre el cubo OLAP de Pentaho y se presentan en formato JSON.

Integración con Pentaho

Estos gráficos demuestran cómo los resultados obtenidos de Pentaho (ya sea desde cubos OLAP, reportes o transformaciones ETL) pueden ser integrados en aplicaciones web personalizadas para crear experiencias de visualización interactivas y modernas.

Flujo de datos típico:

  1. Pentaho ejecuta consultas MDX o transformaciones ETL
  2. Los resultados se exportan en formato JSON o CSV
  3. JavaScript carga los datos en el navegador
  4. Chart.js (u otra biblioteca) renderiza los gráficos interactivos

📊 Bibliotecas de Visualización Utilizadas

  • Chart.js: Biblioteca JavaScript de código abierto para crear gráficos interactivos
  • HTML5 Canvas: Elemento HTML utilizado como superficie de dibujo para los gráficos
  • CSS3: Para el diseño responsivo y el estilo visual de los gráficos
