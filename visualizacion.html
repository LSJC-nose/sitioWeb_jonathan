Visualización de Resultados Gráficos

Presentación interactiva de resultados analíticos

Esta sección presenta gráficos generados a partir de los ejercicios realizados con Pentaho. Los gráficos se han implementado utilizando HTML, CSS y JavaScript para demostrar la capacidad de presentar resultados analíticos de manera visual e interactiva.

Ventas por Producto

Este gráfico muestra las ventas totales por producto, generado a partir del análisis del cubo OLAP.

Explicación Técnica

Este gráfico de barras utiliza Chart.js para visualizar los datos. Los datos se obtienen de consultas MDX ejecutadas sobre el cubo OLAP de Pentaho y se presentan en formato JSON.

Ver código JavaScript 
// Configuración del gráfico de barras
const ctx = document.getElementById('salesByProductChart').getContext('2d');
const salesChart = new Chart(ctx, {
    type: 'bar',
    data: {
        labels: ['Producto A', 'Producto B', 'Producto C', 'Producto D', 'Producto E'],
        datasets: [{
            label: 'Ventas (en miles)',
            data: [120, 190, 300, 250, 180],
            backgroundColor: 'rgba(54, 162, 235, 0.6)',
            borderColor: 'rgba(54, 162, 235, 1)',
            borderWidth: 1
        }]
    },
    options: {
        responsive: true,
        scales: {
            y: {
                beginAtZero: true
            }
        }
    }
});

Tendencia de Ventas Mensuales

Análisis de la tendencia de ventas a lo largo del tiempo, mostrando la evolución mes a mes.

Explicación Técnica

Gráfico de líneas que muestra la evolución temporal de las ventas. Los datos provienen de operaciones de roll-up y drill-down sobre la dimensión de tiempo del cubo OLAP.

Ver código JavaScript 
// Gráfico de líneas para tendencia temporal
const trendCtx = document.getElementById('monthlyTrendChart').getContext('2d');
const trendChart = new Chart(trendCtx, {
    type: 'line',
    data: {
        labels: ['Ene', 'Feb', 'Mar', 'Abr', 'May', 'Jun', 'Jul', 'Ago', 'Sep', 'Oct', 'Nov', 'Dic'],
        datasets: [{
            label: 'Ventas',
            data: [65, 59, 80, 81, 56, 55, 40, 65, 80, 90, 100, 120],
            borderColor: 'rgba(75, 192, 192, 1)',
            backgroundColor: 'rgba(75, 192, 192, 0.2)',
            tension: 0.4,
            fill: true
        }]
    },
    options: {
        responsive: true,
        plugins: {
            legend: {
                display: true
            }
        }
    }
});

Distribución de Ventas por Región

Visualización de la distribución geográfica de las ventas utilizando un gráfico de sectores.

Explicación Técnica

Gráfico circular (pie chart) que representa la proporción de ventas por región. Este tipo de visualización es ideal para mostrar distribuciones y porcentajes relativos.

Ver código JavaScript 
// Gráfico de sectores para distribución regional
const pieCtx = document.getElementById('regionalDistributionChart').getContext('2d');
const pieChart = new Chart(pieCtx, {
    type: 'pie',
    data: {
        labels: ['Norte', 'Sur', 'Este', 'Oeste', 'Centro'],
        datasets: [{
            data: [25, 20, 30, 15, 10],
            backgroundColor: [
                'rgba(255, 99, 132, 0.6)',
                'rgba(54, 162, 235, 0.6)',
                'rgba(255, 206, 86, 0.6)',
                'rgba(75, 192, 192, 0.6)',
                'rgba(153, 102, 255, 0.6)'
            ],
            borderColor: [
                'rgba(255, 99, 132, 1)',
                'rgba(54, 162, 235, 1)',
                'rgba(255, 206, 86, 1)',
                'rgba(75, 192, 192, 1)',
                'rgba(153, 102, 255, 1)'
            ],
            borderWidth: 2
        }]
    },
    options: {
        responsive: true,
        plugins: {
            legend: {
                position: 'right'
            }
        }
    }
});

Comparación de Ventas: Año Actual vs Año Anterior

Análisis comparativo entre períodos utilizando operaciones de análisis de series temporales del cubo OLAP.

Explicación Técnica

Gráfico de barras agrupadas que compara dos períodos. Los datos se obtienen mediante consultas MDX que utilizan funciones de tiempo para comparar diferentes períodos.

Ver código JavaScript 
// Gráfico comparativo de períodos
const compareCtx = document.getElementById('yearComparisonChart').getContext('2d');
const compareChart = new Chart(compareCtx, {
    type: 'bar',
    data: {
        labels: ['Q1', 'Q2', 'Q3', 'Q4'],
        datasets: [{
            label: 'Año Actual',
            data: [320, 450, 380, 510],
            backgroundColor: 'rgba(54, 162, 235, 0.6)'
        }, {
            label: 'Año Anterior',
            data: [280, 410, 350, 480],
            backgroundColor: 'rgba(255, 99, 132, 0.6)'
        }]
    },
    options: {
        responsive: true,
        scales: {
            y: {
                beginAtZero: true
            }
        }
    }
});

Integración con Pentaho

Estos gráficos demuestran cómo los resultados obtenidos de Pentaho (ya sea desde cubos OLAP, reportes o transformaciones ETL) pueden ser integrados en aplicaciones web personalizadas para crear experiencias de visualización interactivas y modernas.

Flujo de datos típico:

  1. Pentaho ejecuta consultas MDX o transformaciones ETL
  2. Los resultados se exportan en formato JSON o CSV
  3. JavaScript carga los datos en el navegador
  4. Chart.js (u otra biblioteca) renderiza los gráficos interactivos

📊 Bibliotecas de Visualización Utilizadas

  • Chart.js: Biblioteca JavaScript de código abierto para crear gráficos interactivos
  • HTML5 Canvas: Elemento HTML utilizado como superficie de dibujo para los gráficos
  • CSS3: Para el diseño responsivo y el estilo visual de los gráficos
