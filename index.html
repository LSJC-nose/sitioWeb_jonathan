Ejercicios Prácticos Realizados

Aplicación práctica de Pentaho en escenarios reales

A continuación se presentan los ejercicios prácticos realizados a lo largo del curso. Cada ejercicio incluye una descripción detallada, instrucciones, y enlaces a los recursos alojados en Google Drive.

Ejercicio 1 - p1

Ver documentación Fundamental

¿Qué hace el ejercicio?

Una empresa de supermercados en Managua, Nicaragua necesita analizar sus ventas junto con los detalles de los productos que comercializa.

Entradas:

  • Archivos CSV con datos de ventas

Salidas esperadas:

  • Generar una tabla resumen que muestre: Total gastado por cada cliente y ciudad con mayor volumen de ventas.
Ver ejercicio

Nota: La carpeta contiene el schema XML, scripts SQL y documentación.

Recurso educativo 8

Ver documentación Avanzado

¿Qué hace el ejercicio?

El objetivo es fusionar ventas con productos para calcular el total de venta por producto y fecha, y luego ampliar el análisis integrando clientes para obtener un resumen de gasto por cliente y la ciudad con mayor volumen de ventas, con preguntas de reflexión sobre los productos y clientes de mayor facturación.

Entradas:

  • clientes.csv
  • productos.csv
  • ventas.csv

Salidas esperadas:

  • Se espera mostrar en un CSV, En qué ciudad se vendió más café y qué cliente gastó más en ese producto?.
Ver ejercicio

Nota: Incluye definiciones de reportes, consultas MDX y capturas del dashboard.

Recurso educativo 20

Ver documentación Avanzado

¿Qué hace el ejercicio?

Guía para poblar datos en una base de datos HSQLDB local a partir de archivos CSV usando Spoon (Pentaho Data Integration) y luego te propone consultas y prácticas para analizar ventas y dimensiones.

Entradas:

  • Archivos CSV con datos de (productos, store, date)
  • Tabla de Hechos (sales_fact)

Salidas esperadas:

  • Se espera que el conteo de filas insertadas coincida con las cifras de tus CSV
  • En particular, para la tabla de hechos (sales_fact) se esperarán 20 filas insertadas, si ese es el tamaño del dataset de ventas.
