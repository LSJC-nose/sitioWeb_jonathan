Ejercicio 1: Recurso educativo 8

Fundamental

¿Qué hace el ejercicio?

Una empresa de supermercados en Managua, Nicaragua necesita analizar sus ventas junto con los detalles de los productos que comercializa.

Entradas:

  • Archivos CSV con datos de ventas

Salidas esperadas:

  • Generar una tabla resumen que muestre: Total gastado por cada cliente y ciudad con mayor volumen de ventas.

Ejercicio 5: Operaciones OLAP

Avanzado

¿Qué hace el ejercicio?

Esta guía te acompaña paso a paso desde el armado de archivos CSV, la carga en Pentaho Data Integration 7.1, la estructura de la base, y la ejecución de todas las operaciones OLAP clásicas con datos en español. El caso de estudio simula ventas de una cadena de tiendas de ropa y tecnología a lo largo de varios meses y regiones.

Entradas:

  • Base de datos
  • Archivos CSV con datos de ventas
  • Operaciones OLAP

Salidas esperadas:

  • Conjunto de tablas, OLAP Funcionales en tiempo real
📁 Ver en Drive Shift+clic para editar/eliminar

Nota: El directorio "ejercicio-5-consultas-mdx" contiene todas las consultas MDX, ejemplos de resultados, y explicaciones de cada función utilizada.

💡 Cómo Utilizar los Recursos en GitHub

  1. Clonar el repositorio: Usa git clone [url-del-repositorio] para obtener todos los archivos.
  2. Navegar a la carpeta del ejercicio: Cada ejercicio está en su propio directorio con nombre descriptivo.
  3. Revisar la documentación: Cada ejercicio incluye un archivo README.md con instrucciones detalladas.
  4. Verificar requisitos previos: Asegúrate de tener Pentaho instalado y las bases de datos configuradas.
  5. Seguir los pasos: La documentación incluye paso a paso para replicar cada ejercicio.
