Ejercicios Prácticos Realizados

Aplicación práctica de Pentaho en escenarios reales

A continuación se presentan los ejercicios prácticos realizados a lo largo del curso. Cada ejercicio incluye una descripción detallada, instrucciones, y enlaces a los recursos alojados en GitHub.

Ejercicio 1: Creación de Cubo OLAP Básico

Fundamental

¿Qué hace el ejercicio?

Este ejercicio introduce la creación de un cubo OLAP básico utilizando Pentaho Schema Workbench y Mondrian. El cubo permite realizar análisis multidimensional sobre datos de ventas.

Entradas:

  • Base de datos relacional con tabla de hechos (ventas) y tablas dimensionales (tiempo, producto, cliente)
  • Schema XML de Mondrian
  • Configuración de conexión a la base de datos

Salidas esperadas:

  • Cubo OLAP funcional con dimensiones y medidas definidas
📁 Ver en Drive Shift+clic para editar/eliminar

Nota: Para acceder al repositorio, clona el repositorio y navega a la carpeta "ejercicio-1-cubo-olap-basico". Incluye el schema XML, scripts SQL y documentación.

Ejercicio 2: Transformación ETL con Pentaho Data Integration

Intermedio

¿Qué hace el ejercicio?

Implementación de una transformación ETL completa que extrae datos de múltiples fuentes, realiza limpieza y transformaciones, y carga los datos en un data warehouse estructurado.

Entradas:

  • Archivos CSV con datos de ventas
  • Base de datos fuente (transaccional)
  • Configuración de conexiones a bases de datos

Salidas esperadas:

  • Data warehouse poblado con datos transformados
  • Archivo de log del proceso ETL
  • Reporte de calidad de datos
  • Transformación (.ktr) funcional y reutilizable
📁 Ver en Drive Shift+clic para editar/eliminar

Nota: El repositorio contiene la transformación .ktr, scripts SQL, archivos de datos de ejemplo y documentación paso a paso en "ejercicio-2-etl-transformacion".

Ejercicio 3: Dashboard Interactivo con Pentaho BA Server

Avanzado

¿Qué hace el ejercicio?

Desarrollo de un dashboard interactivo que combina múltiples visualizaciones (gráficos, tablas, mapas) para presentar análisis de negocio de manera comprehensiva y fácil de interpretar.

Entradas:

  • Cubo OLAP previamente creado
  • Consultas MDX definidas
  • Configuración de Pentaho BA Server

Salidas esperadas:

  • Dashboard publicado en Pentaho BA Server
  • Múltiples visualizaciones interactivas (gráficos de barras, líneas, mapas de calor)
  • Filtros dinámicos para análisis interactivo
  • Exportación de reportes en múltiples formatos
📁 Ver en Drive Shift+clic para editar/eliminar

Nota: Accede a "ejercicio-3-dashboard-interactivo" para ver las definiciones de reportes, consultas MDX y screenshots del dashboard final.

Ejercicio 4: Automatización de Procesos ETL con Jobs

Avanzado

¿Qué hace el ejercicio?

Creación de un job (trabajo) que orquesta múltiples transformaciones ETL, incluyendo controles de flujo, manejo de errores, y programación automática de ejecución.

Entradas:

  • Múltiples transformaciones ETL (.ktr)
  • Configuración de scheduler (opcional)
  • Parámetros de configuración

Salidas esperadas:

  • Job (.kjb) funcional que ejecuta el proceso completo
  • Log de ejecución con estadísticas de cada transformación
  • Notificaciones de éxito/error
  • Proceso automatizado y documentado
📁 Ver en Drive Shift+clic para editar/eliminar

Nota: Encuentra el job principal, transformaciones relacionadas y scripts de automatización en "ejercicio-4-automatizacion-jobs".

Ejercicio 5: Análisis Avanzado con Consultas MDX

Avanzado

¿Qué hace el ejercicio?

Desarrollo de consultas MDX complejas para realizar análisis avanzados sobre cubos OLAP, incluyendo cálculos derivados, funciones de tiempo, y análisis de tendencias.

Entradas:

  • Cubo OLAP con múltiples dimensiones y medidas
  • Requisitos de análisis específicos
  • Herramientas de consulta MDX (Pentaho Analyzer o similar)

Salidas esperadas:

  • Conjunto de consultas MDX documentadas
  • Resultados de análisis (tendencias, comparaciones, rankings)
  • Visualizaciones generadas a partir de las consultas
  • Documentación técnica de cada consulta
📁 Ver en Drive Shift+clic para editar/eliminar

Nota: El directorio "ejercicio-5-consultas-mdx" contiene todas las consultas MDX, ejemplos de resultados, y explicaciones de cada función utilizada.

💡 Cómo Utilizar los Recursos en GitHub

  1. Clonar el repositorio: Usa git clone [url-del-repositorio] para obtener todos los archivos.
  2. Navegar a la carpeta del ejercicio: Cada ejercicio está en su propio directorio con nombre descriptivo.
  3. Revisar la documentación: Cada ejercicio incluye un archivo README.md con instrucciones detalladas.
  4. Verificar requisitos previos: Asegúrate de tener Pentaho instalado y las bases de datos configuradas.
