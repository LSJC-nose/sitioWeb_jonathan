# Sitio Web: Desarrollo de Sitio Web para Bases de Datos Analítica con Pentaho

Este proyecto consiste en el desarrollo de un sitio web de presentación para comprender, explicar y mostrar la aplicación práctica de Pentaho en el análisis de datos y bases de datos analíticas.

## 📋 Descripción del Proyecto

El sitio web incluye explicaciones teóricas y ejercicios prácticos desarrollados durante la clase sobre Pentaho y Business Intelligence. Está diseñado para ser una guía completa que demuestra la aplicación práctica de esta herramienta en escenarios reales de análisis de datos.

## 🏗️ Estructura del Sitio Web

El sitio está compuesto por cuatro páginas principales:

### 1. **Página de Inicio** (`index.html`)
- Vista general de Pentaho como herramienta de Business Intelligence
- Explicación del uso para desarrollo de análisis de datos
- Introducción a la creación de cubos OLAP
- Descripción de flujos de datos y procesamiento

### 2. **Página de Ejercicios** (`ejercicios.html`)
- Listado de ejercicios prácticos realizados durante el curso
- Instrucciones y descripción detallada de cada ejercicio
- Enlaces a recursos alojados en GitHub
- Explicación sobre cómo acceder y utilizar los recursos

### 3. **Página de Visualización** (`visualizacion.html`)
- Presentación de gráficos generados a partir de los ejercicios
- Explicación técnica sobre la visualización con código web
- Ejemplos de código y descripción de gráficos
- Implementación interactiva con Chart.js

### 4. **Página de Créditos** (`creditos.html`)
- Información de los integrantes del grupo
- Redes sociales y datos de contacto
- Descripción de contribuciones
- Agradecimientos y referencias

## 🛠️ Tecnologías Utilizadas

- **HTML5**: Estructura semántica del sitio
- **CSS3**: Estilos modernos y diseño responsive
- **JavaScript**: Interactividad y animaciones
- **Chart.js**: Biblioteca para visualización de gráficos
- **Pentaho**: Herramienta de Business Intelligence
- **GitHub**: Repositorio de código y recursos

## 🚀 Cómo Usar el Sitio Web

### Instalación Local

1. Clona o descarga este repositorio
2. Abre el archivo `index.html` en tu navegador web
3. Navega entre las diferentes páginas usando el menú de navegación

### Requisitos

- Navegador web moderno (Chrome, Firefox, Safari, Edge)
- Conexión a Internet (para cargar Chart.js desde CDN)

### Notas Importantes

- Los enlaces a GitHub deben ser actualizados con las URLs reales de tu repositorio
- La información de los integrantes debe completarse en `creditos.html`
- Los datos de ejemplo en los gráficos pueden ser reemplazados con datos reales

## 🔧 Personalización

### Actualizar Enlaces de GitHub

1. Abre `ejercicios.html` y `creditos.html`
2. Busca los enlaces que apuntan a `#`
3. Reemplaza con las URLs reales de tu repositorio

### Modificar Información de Integrantes

1. Abre `creditos.html`
2. Actualiza las secciones de `.member-card` con:
   - Nombres completos reales
   - Información de contacto (email, LinkedIn, GitHub)
   - Descripciones de contribuciones

### Agregar Datos Reales a Gráficos

1. Abre `visualizacion.html`
2. Busca las funciones de inicialización de gráficos
3. Reemplaza los datos de ejemplo con datos reales de tus ejercicios
